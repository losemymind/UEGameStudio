## 1. 布局图（Layout Diagram）

- ASCII 布局图或文字描述
- 标记：路径、地标、阻挡、入口/出口、流送边界

## 2. 关键路径（Critical Path）

- 玩家必须经过的路线（从入口到目标）
- 每段注明：玩法意图 / 引导方式 / 预期时长

## 3. 可选路径（Optional Paths）

- 探索路径、秘密区域、收集品位置
- 奖励探索但不惩罚主线玩家（对照"不惩罚主线"规则）

## 4. 遭遇设计（Encounter List）

| 遭遇 | 敌人配置 | 位置 | 难度目标 | 玩家技能成长匹配 |
|---|---|---|---|---|
| | | | | |

## 5. 节奏曲线（Pacing Chart）

- 强度随时间的变化：紧张/放松/高潮段
- 休息点、升级点、情绪峰值标记

## 6. 叙事节拍（Narrative Beats）

- 本关卡的故事时刻（经 narrative-director 审核）
- 环境叙事引导（光照/地标/音频隐式引导）

## 7. 音频提示（Audio Cues）

- 音乐何时切换（经 audio-director）
- 重要事件音效触发点

## UE5 关卡构建要点

### World Partition
- [ ] Cell 大小由流送预算决定（城区 ≤64m / 地形 128m / 沙漠 256m+）
- [ ] 游戏性关键内容**不跨 Cell 边界**
- [ ] 常驻内容放 Always Loaded
- [ ] 多人协作关卡使用 OFPA（One File Per Actor）

### Data Layers
- [ ] 按游戏状态分层（导航/战斗/叙事层）
- [ ] 同时活跃 Data Layer ≤5
- [ ] 层间切换有明确触发条件

### PCG
- [ ] 生成规则确定性（同种子同输入同输出）
- [ ] 密度受性能预算约束
- [ ] 优先 Nanite 兼容网格

### 性能预算
- [ ] 帧预算、流送预算以 technical-director 的性能预算表为唯一权威
