# ue-ai-code — AI 代码路径规则

> 路径作用域：`src/ai/**`。该路径下所有代码自动受此规则约束。

## 强制要点

- **AI 预算 ≤2ms/帧**：AI 计算不得突破帧预算（用 Unreal Insights / stat 验证）。
- 参数放数据文件可调（行为树/黑板/数据表），不写死。
- 状态需可视化调试钩子（`VisualLogger` / 调试绘制），便于追踪决策。
- **意图预告**：AI 意图对玩家可感知（威胁指示、起手前摇），不瞬移决策。

## 反例（违规信号）

- 感知查询每帧全量扫描而无预算上限。
- 行为参数硬编码在节点/代码中。
- AI 决策无任何调试可视化手段。
