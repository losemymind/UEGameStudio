# ue-data-files — 数据文件路径规则

> 路径作用域：`assets/data/**`。该路径下所有数据文件自动受此规则约束。

## 强制要点

- **数据合法性阻断构建**：坏数据（JSON 语法错误 / 引用缺失 / schema 不符）必须阻塞构建。
- 命名规范统一，字段文档化 schema。
- 版本化：数据文件带版本号，迁移需方案。
- UE 场景优先用 DataTable / DataAsset 承载，JSON 仅作中间/导入格式时须有校验。

## 反例（违规信号）

- 数据文件改错后构建仍通过（无校验门）。
- 字段含义无文档、命名随意。
- 数据表结构变更无版本与迁移说明。
