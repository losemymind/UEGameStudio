# ue-design-docs — 设计文档路径规则

> 路径作用域：`design/gdd/**`。该路径下所有 GDD 自动受此规则约束。

## 强制要点

- **GDD 8 必需章节**齐全（概述/核心循环/系统/公式/边界/验收/依赖/开放问题）。
- **公式四要素**：每个公式含变量、范围、示例、边界情况，缺一不可。
- **验收标准可测试**：每条 AC 可被客观验证，非"感觉对"。
- **增量撰写**：一次只改一个系统的 GDD，跨系统改动单独提交。

## 反例（违规信号）

- 公式只写表达式无变量定义/范围。
- AC 写"手感好""流畅"等不可测表述。
- 一份提交混杂多个系统设计变更。
