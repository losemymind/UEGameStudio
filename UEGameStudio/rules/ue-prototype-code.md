# ue-prototype-code — 原型代码路径规则

> 路径作用域：`Prototypes/**`（如 `Prototypes/MyIdea/`，独立于 `Source/` 与 `Content/`）。该路径下所有原型代码自动受此规则约束。

## 强制要点

- **标准放宽**：原型允许绕开部分编码标准，但需显式标注为何放宽。
- **隔离**：原型代码放独立子目录，不污染正式代码路径。
- 每个原型必须有 `README`（目标、假设、结论、去留建议）。
- 原型不得部署进正式构建。
- **成功后重写而非迁移**：验证通过的原型重写为正式实现，不直接搬代码。

## 反例（违规信号）

- 原型代码混入 `Source/` 正式模块或 `Content/` 资产路径。
- 原型无 README 无结论，无法判断去留。
- 直接把原型代码当正式实现上线。

业界游戏工作室路径作用域编码规则，蒸馏基准见仓库根 `DISTILLED-REFERENCE.md` §6.3。
