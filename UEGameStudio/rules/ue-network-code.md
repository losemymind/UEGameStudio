# ue-network-code — 网络代码路径规则

> 路径作用域：`src/networking/**`。该路径下所有代码自动受此规则约束。

## 强制要点

- **服务器权威**：客户端永不直接决定游戏状态；所有状态变更经服务器校验（`_Validate` 不可省略）。
- 消息/RPC 版本化，破坏性变更需迁移方案。
- 客户端预测需回滚/和解机制，不裸放预测结果。
- **带宽预算**：声明并遵守复制频率与载荷预算（目标 <10KB/s/客户端）。

## 反例（违规信号）

- `Server` RPC 无 `_Validate` 或未校验输入。
- 高频率属性无 `COND_*` 条件、未量化直接复制。
- 客户端直接改权威属性。
